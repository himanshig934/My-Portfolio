# My-Portfolio

A modern and fully responsive personal portfolio website designed and developed using HTML and Tailwind CSS. The website showcases professional skills, work experience, and projects with a clean dark-themed UI. It is optimized for all screen sizes, ensuring a smooth user experience across desktops, tablets, and mobile devices.


Website Sections :

1. Hero / Introduction Section
2. About Me
3. Work Experience
4. Portfolio Projects
5. Contact Section
